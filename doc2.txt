package mavenpract.mavenpract;

import java.io.FileReader;
import org.json.simple.JSONObject;
import org.json.simple.parser.JSONParser;

public class ReadJson {

	public static void main(String[] args) throws Exception {
		JSONParser parser = new JSONParser();
        JSONObject student = (JSONObject) parser.parse(new FileReader("JSON/student.json"));

        System.out.println("Firstname:" + student.get("firstname"));
        System.out.println("Lastname:" + student.get("lastname"));
	}

}

1. Create the Maven Project
File → Project → Maven → Maven Project → Next → In filter: org.apache.maven.archetypes → maven-archetype-quickstart → Next → Give Group Id & Artifact Id → Finish → In terminal click Y → Build success.

2. Create the Java Class
Right click on src/test/java → New → Create Class → ReadJson → Enter → ReadJson.java.

3. Create the JSON Folder and File
• Right click on lab2 (your project) → New → Folder → "JSON" (Name of folder)
• Right click on Json folder → New → File → "student.json" → Write code (backend)

4. Add Dependencies and Run
For dependencies go to Chrome → Search Maven repository → Mvn repository → Search simple json → json.simple → Select 1.1.1 version → Copy code → Then paste into pom.xml → Run → Get output code.
